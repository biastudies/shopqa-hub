# ShopQA Hub

Protótipo acadêmico interativo de uma plataforma de QA para e-commerces.
Todas as execuções de teste são **simuladas**: nenhum teste real é rodado em ferramentas externas.

Slogan: Mais controle. Mais rastreabilidade. Mais confiança.

## Como abrir
- Online: veja o link do GitHub Pages abaixo (preencha após publicar).
- Local: dê duplo clique em `index.html`. Não precisa de instalação nem de internet.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo, `shopqa-hub`).
2. Envie `index.html` e `README.md` para a branch `main` (botão **Add file > Upload files**).
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e clique em **Save**.
5. Aguarde cerca de 1 minuto. O link será `https://SEU-USUARIO.github.io/shopqa-hub/`.

## Antes da apresentação
- Clique em **Restaurar dados demo** na barra lateral.
- Roteiro: Dashboard > Suítes (criar e executar) > Execuções > Evidências > Modelo V > Relatórios.
- Os dados ficam no `localStorage` do navegador de cada pessoa.

## Tecnologia
HTML, CSS e JavaScript em um único arquivo, com gráficos em SVG.
